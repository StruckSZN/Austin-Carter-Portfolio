# Austin Carter - Developer Portfolio

## Project Overview

This project is a personal developer portfolio website created to
showcase my education, technical skills, professional experience,
programming projects, and career interests.

The website was created as part of my Computer Programming coursework
and demonstrates my understanding of HTML, CSS, JavaScript, responsive
web design, and GitHub.

---

## Purpose

The purpose of this portfolio is to provide a professional online
presence where I can showcase my programming experience and projects.

The website includes information about my education, technical skills,
professional experience, programming projects, and contact information.

---

## Website Pages

The portfolio contains the following pages:

### Home

The Home page introduces me and provides an overview of my programming
background, skills, and current areas of interest.

### About

The About page provides additional information about my programming
background, education, interests, and career goals.

### Resume

The Resume page contains my professional summary, technical skills,
education, hands-on technology experience, professional experience,
and additional qualifications.

### Projects

The Projects page showcases programming projects and coursework,
including descriptions, technologies used, and links to their
corresponding GitHub repositories.

### Contact

The Contact page provides ways to connect with me professionally,
including email, GitHub, and LinkedIn.
